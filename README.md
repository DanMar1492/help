## GitHub Copilot Model Availability

### Claude Opus 4.6 Outage (March 2026)

Claude Opus 4.6 experienced a brief service disruption in early March 2026 caused by an Anthropic global outage. This affected GitHub Copilot users who rely on this model.

**If Claude Opus 4.6 is not working for you, try these steps:**

1. Check the [Anthropic status page](https://status.claude.ai) and [GitHub Copilot status](https://githubstatus.com) for ongoing incidents.
2. Restart your IDE (VS Code, JetBrains, etc.) and sign out then back into GitHub Copilot.
3. If on an enterprise plan, confirm with your admin that Claude Opus 4.6 is enabled in Copilot settings.
4. As a temporary workaround, switch to another available model (e.g., GPT-4o or GPT-4.1 mini) using the model picker in Copilot Chat.
5. Wait a few hours — rollout delays and recovery from outages can take time to propagate fully.

The outage is now resolved. If you still cannot access Claude Opus 4.6, waiting or contacting GitHub Support is recommended.
